# Healthcare PMO & Delivery Control Center

A responsive, browser-based portfolio demonstration of a Project Management Office hub. Built with HTML, CSS and JavaScript to showcase portfolio visibility, delivery governance, intake prioritization and executive reporting.

## Open the app
Open [index.html](./index.html) locally, or enable GitHub Pages for this folder/repository to publish it as a static site.

## What it demonstrates
- Portfolio health KPIs, project search, filtering and sorting
- Project creation, editing and deletion
- Status, progress, priority, due dates, risks, issues and next milestones
- Project intake with approve/decline workflow
- Executive status report with downloadable text summary
- JSON import/export and browser-local persistence
- Responsive layout for desktop and mobile

## Demonstration scenarios
The initial records are fictional and represent common healthcare delivery contexts:
- Multi-country physician market research
- Hospital electronic prior authorization (ePA) implementation
- Salesforce CRM enhancement
- Prior authorization workflow improvement

## Project-management concepts represented
Portfolio reporting, stakeholder ownership, prioritization, delivery health, milestone tracking, risk and issue management, intake governance, and executive communication.

## Run locally
Download the folder and open `index.html` in a modern browser. No build step or external dependency is required.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and the appropriate folder, then save. If publishing this subfolder is not offered as a source, place the app in a dedicated repository or use a GitHub Actions Pages workflow.

## Limitations
This is a front-end portfolio demo. Data is stored in the current browser only; it is not shared with other users and is not a secure production system. Export JSON regularly to back up changes. All sample records are fictional.
