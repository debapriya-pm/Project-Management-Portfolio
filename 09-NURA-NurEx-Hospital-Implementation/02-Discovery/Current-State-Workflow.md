# Current-State Workflow

Clinical need → EHR information → local protocol/reference → manual calculation/lookup → medication preparation → verification → administration → documentation/handoff.

## Observed process risks
- multiple sources
- manual searching
- inconsistent local workflow
- unclear ownership of content updates
- limited visibility into usage and issues

## Discovery questions
What is the approved source of truth? Which medications are highest priority? Which users need which access? What must integrate with the EHR? What can safely be deferred from the pilot?
