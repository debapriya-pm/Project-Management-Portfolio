# Project Charter — NurEx ED Implementation

**Sponsor:** SLRH Executive Sponsor (fictional)  
**PM:** NURA Project & Operations Associate (simulation)  
**Duration:** 6-week implementation + 2-week hypercare

## Problem
SLRH's ED medication-preparation workflow requires clinicians to move between multiple information sources, creating variation and operational friction.

## Objective
Deploy NurEx in the ED using approved institutional medication content, validated workflows, trained users and controlled go-live governance.

## Scope
**In:** discovery, requirements, workflow mapping, formulary mapping, configuration, access/security readiness, UAT, training, cutover, hypercare, adoption reporting.

**Out:** enterprise rollout, EHR replacement, autonomous clinical decision-making, creation of new clinical dosing guidelines, unrelated pharmacy redesign.

## Constraints
Six-week timeline; limited clinical staff availability; hospital approval processes; clinical content must be validated before production; EHR integration may not be available for pilot.

## Milestones
W1 discovery; W2 requirements/configuration baseline; W3 configuration; W4 UAT; W5 training/readiness; W6 go-live; W7–8 hypercare.

## Governance
Weekly executive update; twice-weekly workstream meeting; daily issue review during go-live week.

## Approval gates
Requirements baseline → configuration approval → UAT exit → go/no-go → hypercare exit.
