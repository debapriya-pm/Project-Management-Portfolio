# Lessons Learned

## Worked
- Early pharmacy involvement reduced late content changes.
- Super users created leverage for training.
- One RAID log gave the COO visibility without excessive reporting.
- Explicit go/no-go gates made readiness evidence-based.
- Phase 2 scope protected the launch baseline.

## Did not work
- EHR integration assumptions were too optimistic.
- Training initially ignored shift patterns.
- Users interpreted enhancement requests as implementation commitments.

## Next time
Confirm technical constraints on day one; identify super users in week one; establish change-control thresholds early; define adoption metrics before training.

## Benefits review
At 30 days compare adoption, competency, workflow duration, support trend, feedback and content-update cycle time.
